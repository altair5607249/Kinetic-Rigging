# Walking Simulator — Veryn's Headspace
Veryn's Headspace is a 2D walking simulator currently in pre-alpha.

## Context
As a practical way of enhancing my C++ skills, I've decided to develop a game with C++!

Using C++ to build games allows me to become more fluent with it while doing what I love! It feels less like studying this way, and more like self-entertainment.

At the same time, I'm preparing myself for the more laborious work by taking on an actual project; in any case, it's important to not just stare at isolated code when learning a language. You should engage with it in ways that challenge you, in ways you might find interesting, or maybe in ways that are fun *and* challenging! I find that to be a great workflow regarding any topic, but that could just be my opinion.

Either way, I might publish releases of this walking simulator as I continue other C++ projects; these releases may or may not overlap with the releases of other projects.
